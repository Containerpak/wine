# Wine Base

The Containerpak Wine image is a reusable desktop base for applications that
run Wine or Proton. It provides the graphics, audio, input, Vulkan, multimedia
and 32-bit system libraries needed by those applications, but it does not ship
Wine, Proton, Winetricks, Gecko or Mono.

The image is published at `ghcr.io/containerpak/wine:main` by GitHub Actions.
